Импорт магазинов для ТО

По одному магазину в строке (столбец из Excel или файл .txt). Добавятся в выбранный месяц, повторы пропускаются.

Какие листы использовать?

Скрытые листы и сводные сняты по умолчанию. Столбцы определены автоматически, при ошибке поправьте вручную. Статус берётся из столбца «Статус»; если его нет, объект считается выполненным, когда дата уже наступила. Загрузка заменяет данные этих листов на сайте.
