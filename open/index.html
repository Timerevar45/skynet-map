Импорт магазинов для ТО

По одному магазину в строке (столбец из Excel или файл .txt). Добавятся в выбранный месяц, повторы пропускаются.

Какие листы использовать?

Скрытые листы и сводные сняты по умолчанию. Столбцы определены автоматически, при ошибке поправьте вручную. Статус берётся из столбца «Статус»; если его нет, объект считается выполненным, когда дата уже наступила. «Общий срок» задаёт одну дату на всю задачу (например, до 20 ноября), на выполнение он не влияет. Загрузка заменяет данные этих листов на сайте.

Основные каналы: магазины и IP

Два столбца из Excel (название магазина и IP основного канала) или файл .xlsx / .txt. Повторная загрузка обновляет IP у существующих магазинов. IP видны только админам.

Добавить задачу / объекты

Обязателен только магазин. Остальное по порядку через Tab или «;» (можно скопировать несколько столбцов из Excel). Статус «да», «готово» или «выполнено» значит выполнено. Несколько магазинов можно вставить разом.
